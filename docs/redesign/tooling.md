# Tools and cost

No new package or service dependency was added. No purchase or paid API call was made. Model usage is charged or metered under the user's existing Codex account and is separate from tooling costs. No extra model or independent agent was invoked.

| Tool | Purpose | License or terms | Incremental tool cost | Restrictions and checks |
|---|---|---|---|---|
| Hugo Extended and Tailbliss | Build static HTML and responsive WebP images | Apache-2.0 for both, upstream metadata and theme LICENSE | $0 | Local noninteractive build. Theme stays pinned. |
| Node.js, npm | Run existing lockfile and scripts | MIT and Artistic-2.0 respectively, bundled dependencies carry their own licenses | $0 | Installed locked dependencies with lifecycle hooks disabled. Registry required for uncached packages. |
| PostCSS, postcss-cli, Tailwind, Autoprefixer, cssnano | Existing CSS build | MIT, package-lock metadata | $0 | Local execution. No component install service. |
| UI UX Pro Max | Accessibility, layout and interaction guidance | MIT, upstream repository | $0 | Consulted source text. No launcher, installation or service. |
| Impeccable | Hierarchy, cognitive load and rendered design review | Apache-2.0, upstream repository | $0 | Used the written rubric and craft guidance. The automated command downloads a binary and calls for independent agents. No launcher, live editing or paid model use. |
| Playwright | Keyboard, navigation, state, responsive checks and screenshots | Apache-2.0, installed package LICENSE | $0 | Used the existing local installation, an alpha build, and enabled Chromium sandboxing. The workflow can use an independently installed Playwright. |
| Chrome for Testing | Local browser engine | Google Chrome distribution terms, Chromium includes BSD and third-party licensed code | $0 | Existing test browser used locally with permission. Browser binary is not distributed with the site. |
| Lighthouse and axe-core | Synthetic page measurements and accessibility audits | Apache-2.0 and MPL-2.0, lockfile and bundled licenses | $0 | Existing local versions 10.1.0 and 4.6.3. No cloud or hosted dashboard. Older axe has incomplete support for modern color syntax. |
| Python and Pillow | Local fixture server, route crawl, inspection of screenshot and photo contact sheets | PSF and MIT-CMU | $0 | Installed locally. Image derivatives shipped by the website are generated by Hugo. |
| Git, GitHub CLI and curl | Branch management, license and maintenance checks, read-only upstream documentation | GPL-2.0, MIT and curl license respectively | $0 | GitHub API applies account rate limits to metadata lookup. Building and serving require no GitHub API calls after checkout. |

The two design repositories and the Hugo, Playwright, Lighthouse and axe-core projects showed recent upstream activity. The existing lockfile is older. A November 22 npm audit reported zero production advisories when development packages were omitted and 44 findings in the development tree, including 22 high and one critical. The build environment needs a separate dependency-maintenance pass. The generated site serves static assets and has no npm server process.

Sources: [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), [Impeccable](https://github.com/pbakaus/impeccable), [Hugo](https://github.com/gohugoio/hugo), [Playwright](https://github.com/microsoft/playwright), [Lighthouse](https://github.com/GoogleChrome/lighthouse), [axe-core](https://github.com/dequelabs/axe-core).
